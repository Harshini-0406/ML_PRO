# DSA Architecture

## Core usage

### Hash Map
- Student lookup by ID or email
- Question lookup by questionId
- Performance lookup by student and window

### Trie
- Question search autocomplete
- Topic autocomplete
- Subject label search

### Graph
- Topic dependency traversal
- Learning path mapping
- Prerequisite graph for exam subjects

### Heap / Priority Queue
- Leaderboard ordering
- Recommendation prioritization
- Urgent revision item ranking

### Tree
- Subject -> Topic -> Subtopic -> Question hierarchy
- Learning structure for adaptive planning

### Sorting and Search
- Ranking performance and progress
- Student filtering and question retrieval
- Exam comparison logic

## Why it matters

These data structures let ExamIQ provide intelligent search, ranking, and personalized action recommendations without forcing all logic into a single flat dataset.
