# UI/UX Design System

## Visual foundation

- Dark-first theme with deep navy, indigo, violet, cyan, emerald, amber, and rose accents
- Glassmorphism cards, gradient highlights, subtle glow, floating widgets, and layered surfaces
- High contrast typography for clarity and trust
- Premium SaaS card system with minimal clutter and strong hierarchy

## Component patterns

- Card variants: primary, elevated, glass, info
- Button variants: primary, secondary, ghost, danger
- Input variants: filled, bordered, search
- Status badges: low, medium, high, success, risk

## Accessibility and responsiveness

- Semantic HTML structure
- Keyboard-friendly controls
- Focus rings and contrast-safe color usage
- Mobile-first layout with collapsible sidebar patterns
