- Hero, problem statement, intelligence pipeline, preview analytics, feature cards, exam support

## Phase 6: ML and AI intelligence
- Score prediction endpoints

- Adaptive plan generation
- Recommendation engine
- Learning path graph

## Phase 8: leaderboards, profile, admin, and reports
- Student management and admin experiences
- Reporting and export workflows

## Phase 9: backend and MongoDB integration
- Mongoose models and connectivity
- Seed data and validation

## Phase 10: testing, optimization, deployment prep
- Unit, component, API tests
- Build verification and runtime checks
