# ExamIQ

ExamIQ is an AI-powered competitive exam intelligence platform that transforms mock-test data, study behavior, and performance trends into actionable preparation guidance.

## Overview

The platform combines:

- AI-powered readiness prediction
- Data science-driven performance analysis
- Machine learning score and success prediction
- Personalized study planning
- DSA-backed recommendation, search, and dependency tracking
- Role-aware student and admin experiences

## Solution Architecture

This repository follows a modular multi-service design:

- Frontend: React + TypeScript + Vite + Tailwind
- Backend: Node.js + Express + TypeScript + MongoDB
- ML Service: Python + FastAPI + scikit-learn + XGBoost
- Documentation: Architecture, API, ML, and DSA notes

## Quick Start

See the docs and setup guides in the project folder before running the services.

## Main Goals

- Predict exam readiness and likely score
- Detect weak topics and risks early
- Generate personalized study plans
- Improve exam strategy through analytics and recommendations
- Support both student and admin workflows
